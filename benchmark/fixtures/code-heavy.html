Building a small command

This example shows the complete path from a source file to a useful result.

Implementation

export function readConfig(path: string): Config {
  const source = readFileSync(path, 'utf8')
  return JSON.parse(source) as Config
}

export async function run(path: string): Promise<number> {
  const config = readConfig(path)
  return execute(config)
}

The implementation keeps parsing separate from execution. That separation makes both parts simple to test and easy to replace.
